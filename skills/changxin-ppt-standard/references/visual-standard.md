# 视觉规范

## 模板与整体结构

- 修改已认可的文件时，沿用它的网格、页边距、标题位置、Logo大小和页脚。不要自行增加目录装饰、结尾文案或新章节。
- 有公司原模板时使用原封面，按提供的信息填写汇报人、部门、指导人及时间，保留原信息区位置。未知姓名或日期不猜填。
- 目录必须和正文板块对应。结尾沿用模板原页，例如模板是“The End”就直接保留；其他模板不强行套用这个结尾。
- 所有内容页沿用模板的品牌页脚和Logo。页脚不可漏页，Logo保持原比例与一致尺寸，不重绘商标。
- 没有模板时默认16:9、白底、统一蓝色表格；说明这是规范风格稿，不宣称复刻官方模板。

## 配色

| 用途 | 默认值 | 应用 |
| --- | --- | --- |
| 主题蓝 | HEX #0154A6 / RGB 1,84,166 | 标题、表头、主要图标、品牌强调 |
| 白色 | #FFFFFF | 正文表格底色、蓝底文字 |
| 深色 | 高对比深灰或黑色 | 白底图内说明，可沿用模板 |
| 黄色 | 取用现有图示的清楚黄色 | 少量动作、滚轮、方向箭头，不作为第二主色 |
| 边线 | 与模板一致的浅灰蓝 | 较细，不抢占视觉重点 |

这些是本技能的工作配色，不是官方VI认证。用户现行品牌文件优先。蓝底白字的规则也适用于图中的层别或部件名称，不仅是表头。白底说明不随之改成白字。底色较浅时检查实际对比度，不机械套用配色。

原图文字需要调整时，优先取得可编辑源文件或更清晰原图；仅在用户授权范围内修改标注。不能用生成图片重画证据、改变缺陷形态或数值，也不能用裁剪隐藏影响结论的内容。

## 字体和层级

- 字体家族尽量不超过3种，优先一套中文无衬线字完成正文与表格，利用字重和字号区分层级。已有模板中的封面字体可以保留。
- 同级标题、表头、正文保持相同字号。正文不大于小标题，标题图标和文字在视觉上居中对齐。
- 以原模板字号为准。无模板的16:9稿可从大标题28–32pt、小标题22–26pt、正文18–22pt起步；它们是起点而非固定标准，按投影阅读距离检查。
- 内容过多时先删冗余、放大证据图或拆页，不不断缩小文字。仅在解释单位、统计口径或关键条件时保留简短辅助字。
- 不在页面底部加入长段演讲稿、设计说明或“待确认”等制作过程标签。确实影响结论的条件仍应简短、清晰地保留。

## 横向表格版式

采用原生可编辑表格，图片与文本保持独立可编辑，避免整页变成一张截图。表头蓝底白字，正文各行统一白底，不加入交替色或单独强调一整行，除非用户明确要求。

依据页面任务选择结构，不必每页强行相同列数：

| 页面任务 | 推荐结构 |
| --- | --- |
| 新旧标准对比 | 旧版 / 新版，必要时按相同项目分行 |
| 标准化汇总 | 文件范围 / 标准化内容 / 升级目的 |
| 问题改善 | 前期现象或记录 / 改善措施 / 后续记录或结果 |
| 收获总结 | 收获方向 / 对应工作 / 具体收获 |
| 创新展示 | 链接区域 + 总体介绍 / 相关展示 |
| 工作展望 | 提升方向 / 行动计划 / 相关记录 |

保持这些页面共同的标题起点、表格宽度、表头高度、边线和内边距。用户给定的题头原样保留，不随意换同义词。

列宽随实际内容调整。三栏改善页可以从24% / 56% / 20%起步，但不能把这套比例机械套到所有页。措施图应占主要空间，短结果栏紧凑。少量信息通过调整列宽、图片大小和垂直对齐处理，不增加填充性文案。

有实际收获且能承接下一页时，可以在最下面合并一行写一句总结。没有新信息就省去，不强迫每页加相同口号。

## 图片与数据图

- 原始高清图优先，完整展示需要讲述的步骤、注意事项与风险点。图示主体大小应便于投影阅读。
- 图像放大状态也要检查清晰度，不能只看缩略图。保留原比例，避免拉伸、过度裁切或重复压缩。
- 图片下用一句短标题说明“这是什么”，不堆长段说明。同一证据图一般只出现一次，动画放大副本不算新的内容页。
- 网页展示截取真实功能或具体内容，避免只放目录或大段文字。桌面与手机截图应展示用户指定的功能。
- 比例、单位和数轴准确。颜色美化不得把不利数据隐藏或把不同口径伪装为同一序列。
